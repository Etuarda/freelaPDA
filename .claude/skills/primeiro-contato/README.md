# Skill `primeiro-contato`

Escreve a primeira mensagem de WhatsApp ou Instagram para oferecer um serviço a um pequeno
negócio, a partir dos motivos que o projeto `captacao-freelas` calcula ("não tem site",
"Instagram ativo" etc.). O tom, o formato e o que nunca dizer estão em
[reference.md](reference.md).

**Para usar em outro projeto:** copie esta pasta para `.claude/skills/primeiro-contato/` do
seu projeto e reinicie o Claude Code. Ela espera um `src/cli.js` que imprime os leads
priorizados (como o deste repositório). Depois, peça "escreve a mensagem para abordar
<negócio>" ou chame `/primeiro-contato <negócio>`.
